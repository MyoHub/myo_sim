# Passive joint moments and thenar muscles

The right-arm reference model (`myo_sim/models/arm/assets/`) includes the thenar
muscles and passive joint moments of the hand, so every composed model with an arm or a
hand (`myofullbody`, `myotorso_arms`, `myoarms`, `myohands`, `myoarm_r`, `myohand_r`, ...)
has them on both sides. There is no flag. The previous models are in earlier release
tags.

| Content | Where |
| --- | --- |
| thenar attachment sites | `myoarm_r_chain.xml`, on their bodies |
| thenar tendons (AdP, FPB, APB) | generated block of `myoarm_r_tendon.xml` (`scripts/generate_thenar_muscles.py`) |
| thenar muscles | generated block of `myoarm_r_muscle.xml` (same script) |
| passive joint-moment springs (`<fixed>` tendons) | generated block of `myoarm_r_tendon.xml` (`scripts/fit_passive_moments.py`) |

The left arm is mirrored from these files as usual. Hand models keep the thenar muscles
and the springs through the arm-to-hand pruning in `build/hand.py` (see
`build-and-composition.md`, *Hand models by pruning*).

**Downstream changes.** The thenar muscles add 3 actuators per hand (`AdP_r`, `FPB_r`,
`APB_r`; `_l` on the left), after each arm's other muscles:
`myoarm_r` 63 -> 66, `myoarms` 126 -> 132, `myohand_r` 39 -> 42, `myohands` 78 -> 84,
`myofullbody` 416 -> 422. Left-arm and leg actuator indices shift by 3 or 6. The
polynomial tendon stiffness needs MuJoCo >= 3.7, the package floor.

**Generated blocks.** Script-written XML sits between `<!-- BEGIN generated by
scripts/<script>; do not edit by hand -->` and `<!-- END generated by scripts/<script> -->`
inside the hand-written files. The scripts rewrite only their block
(`myo_sim.build.hand_data.write_generated_block`). The JSON tables in `build/data/` are
the provenance and fitting input. `tests/test_passive_thenar.py` checks that each block
is exactly what its script writes from the table. To change a value, edit the table and
rerun the script (`fit_passive_moments.py --xml-only` rewrites the block without
refitting).

## Passive joint moments (`build/data/passive_joint_moments.json`)

Each row is one joint. A spring segment is a one-joint fixed tendon
(`passive_<row>_<pos|neg>[i]_r`, mirrored to `_l`). Its spring acts beyond an onset
angle (absolute, in joint coordinates) with restoring moment `-(k0 x + k1 x^2 + k2 x^3)`.
MuJoCo and mujoco-warp evaluate it natively (`tendon_lengthspring`,
`tendon_stiffnesspoly`). Segments can be stacked per side.

Every `measured` and `assumed` row is part of the model; the status is provenance. Each
of these rows cites its source and keeps the source curve (published model and
parameters) under `source_curve`.

**Fit to the residual.** `scripts/fit_passive_moments.py` fits the springs to the
source curve minus the model's own passive muscle moment at act = 0. It evaluates them
at the source's posture (`subtract_model_muscles.posture_deg`), over the source's angle
range. Muscles and springs therefore do not count the same moment twice.
- A source that covers only part of the passive moment subtracts only the muscles it
  includes. Knutson's intrinsic MCP component subtracts only that digit's interossei and
  lumbrical; the extrinsic component belongs to FDS/FDP/EDC/EI.
- The fit uses non-negative coefficients (restoring springs). Where the muscles already
  exceed the source, the residual still enters the fit, so a spring there pays for adding
  to the excess (`model_excess_max_Nm`).
- A side, or a row, whose residual is nowhere restoring gets no spring. `fit.spring`
  then records why, as for pro/supination.

**Refit triggers.** The springs, and the finger damping below, are residuals over the
model's own muscles: they supply what the muscles do not. Refit them
(`fit_passive_moments.py`) whenever the muscle model changes, for example compliant tendons
(the tendon stretch moves each fibre's operating point), different passive force-length
curves or a muscle model whose fibres add damping of their own, and whenever the muscles
crossing a joint change (paths, parameters, added or removed muscles). The damping is
applied in full today because the rigid-tendon muscles add none at act = 0; with fibre
damping it becomes the measured value minus the muscles' share.

RMS of the total model moment (muscles + springs) against the source curve over the
source's range (N m). "Muscles only" is the model without springs. "Before" are the
springs of the earlier version, fitted without subtracting the thenar muscles or, for the
wrist and Knutson rows, any muscle; for the index MCP, "Before" is the residual fit with the old
RI2 path (see below).

What remains is muscle excess that a restoring spring cannot remove:
- Thumb MP: FPB and AdP alone give up to 0.091 N m against a 0.061 N m peak.
- PIP 5: the digit-5 extensors give up to 0.166 N m against 0.052 N m. The flexion-side
  spring is dropped because the residual there pushes away from rest.

The two CMC rows now partly cancel AdP's passive adduction and extension moment. Their
residual equilibrium moved toward the abduction / extension limits, because AdP's
passive force exceeds Domalain's total over most of the range. A better AdP path (Barry
et al. 2018: two heads, wrapping) is the real fix.

Mappings and caveats (details in each row's `notes`):

- **Formica 2012** (healthy, n = 10): direction-specific linear stiffness about neutral,
  valid within about +-17 deg; no end-range stiffening.
- **Domalain 2010** (healthy, n = 10): Mp is the *external* moment (internal = -Mp), in
  Chao et al. TMC angles relative to each subject's maxima; aligned with MyoHand's
  extension / abduction limits. Left out: the F-E abduction term (averaged coefficients
  give ~11 N m at the resting adduction vs <= 1.9 N m measured) and the A-A flexion term
  (single-joint springs). The adduction side is linear: a cubic extrapolates to 5.5-6.8
  N m at MyoHand's adduction limit, 26 deg past the measured span.
- **Hollister 1992**: thumb CMC axes 72.7 +- 8.4 deg apart, flexion-extension in the
  trapezium, abduction-adduction in the metacarpal, not intersecting. MyoHand's are 80.9
  deg apart and intersect (both on `firstmc`); the Domalain mapping is by joint limits.
- **Knutson 2000** (healthy, n = 8, Table 1 medians): only the intrinsic component; the
  extrinsic component belongs to the extrinsic muscles. MyoHand's FDS/FDP/EDC/EI give at
  most 1.2 N cm at the index MCP (Knutson: up to 30 N cm), so tenodesis is missing until
  their passive tension is restored (a separate change).
- **Kamper 2002** (Table 2 static torque, wrist neutral, other finger joints fixed;
  operating points -10..60 deg): total moments, so the model's muscle moment is
  subtracted. Outside -10..60 deg the torque is held at its edge values: the PIP cubic
  turns back toward flexion above 45.5 deg (+0.064 N m at 90 deg), the DIP cubic reaches
  -0.25 N m at 90 deg. Kamper's simulation used the angle relative to the proximal joint;
  measured with that joint at neutral, which is what a single-joint spring reproduces.
  The DIP cubic crosses zero near -14 deg although the paper states 7 deg as the
  zero-torque DIP angle; used as published. Its damping B is applied (below).
- **Li 2006** (index PIP, MCP 0 / 60 deg): kept as a validation target in the PIP row.
- **Assumed rows** are transfers, not measurements of those joints: Barry et al. 2018 set
  the thumb MCP / IP equal to the index MCP / PIP; McFarland et al. 2023 scaled the index
  PIP/DIP curves for digits 3-5 (scale factors not available, so transferred unscaled).
- Model issues found on the way: an RI2 path jump between 10 and 15 deg MCP flexion (fixed,
  below); no MCP hyperextension (range starts at 0 deg; measured passive extension reaches -65 deg,
  Binder-Markey 2021 data); the thumb muscles at the MP joint and the digit-5 extensors at
  PIP 5 exceed the transferred totals, and AdP exceeds Domalain's CMC totals (see above).

## Finger joint damping

Kamper et al. 2002 (Table 2) measured the damping B of the index MCP, PIP and DIP: 0.0142,
0.0105 and 0.0081 N m s/rad. MyoHand's finger joints had the class damping of 0.05 N m s/rad,
so against passive moments of a few N cm the fingers settled over seconds and lagged a wrist
moving at 20 deg/s. Each finger flexion row now has a `damping` entry (value, source, status,
previous value): measured for the index, transferred unchanged to digits 3-5 (status
`assumed`, as for their stiffness). `fit_passive_moments.py` writes these values as the
`damping` attribute of the twelve finger flexion joints in `myoarm_r_chain.xml`; every other
joint keeps its class damping. The thumb keeps 0.05: Domalain 2010 reports static moments only
and no thumb MP / IP damping was measured, so its rows keep the Kamper index values under
`damping_reference`, not applied.

At the 2 ms Euler step with the class armature (1e-4) these values are stable: 6 s
random-excitation rollouts of `myohand_r` and `myoarm_r` stay finite, with the same rate of
step-to-step velocity reversals as with 0.05 N m s/rad, and relaxed hands settle. This changes
the dynamics of every downstream model with a hand.

## RI2 path

RI2's insertion (`RI2-P3_r`) lies on the surface of `2ndmcp_ellipsoid_wrap_r` at MCP 0 deg and
inside it from about 10 deg flexion. MuJoCo skips a wrap whose end point is inside the
cylinder, so the path snapped to the straight line and its length dropped by 7.1 mm between
MCP 10 and 15 deg (and by up to 10 mm across MCP abduction). Below the jump the sidesite,
which projects onto the dorsal-distal side of the cylinder, forced a dorsal wrap: an MCP
extension moment arm, and a length of up to 50 mm against a `lengthrange` of 31.4-42.4 mm,
so RI2's passive force held the index MCP near 7 deg. RI2 now runs through its three sites
without that wrap, and the unused sidesite is gone. The path is continuous, its length
(31.4-42.1 mm) lies within the unchanged `lengthrange` (so slack and optimal fibre length are
unchanged), and its MCP moment arm is flexor (3-8 mm) throughout.

A scan of every hand and wrist muscle's length against each crossed joint (four
random-background sweeps of every joint) found no other jump above 0.2 mm. EDC2, EDC4 and
EDC5 show steps of 0.15-0.22 mm against wrist deviation where their torus wraps engage; these
torus wraps have their sidesite at the wrap centre, which MuJoCo treats as an inside wrap, a
different mechanism, and they are left as they are. The same wraps account for the largest
CPU / mujoco-warp differences in muscle length (below 0.5 mm here, larger on dev).

## Thenar muscles (`build/data/thenar_muscles.json`)

Adductor pollicis (AdP), flexor and abductor pollicis brevis (FPB, APB) on every hand,
in the arm's `myoarm_forearm_muscle` class (the class of OP).

| Muscle | PCSA (cm2) | Peak force (N) | Optimal fibre length (mm) | Pennation (deg) | MUSIC force (N) |
| --- | --- | --- | --- | --- | --- |
| AdP (Jacobson "AddP") | 1.94 | 167.5 | 34.0 | 17.3 | 100.0 |
| FPB | 0.66 | 57.0 | 41.5 | 6.2 | 80.0 |
| APB (Jacobson "AbPB") | 0.68 | 58.7 | 41.6 | 4.6 | 42.7 |

- **Sites**: MUSIC (Xu et al. 2026, ACM TOG, doi:10.1145/3811402; code MIT, see
  `build/data/LICENSE-MUSIC.txt`), on MyoHand's own bodies (frames identical to MUSIC's;
  note MUSIC's `cmc_flexion` / `cmc_abduction` names are swapped relative to MyoHand).
- **Architecture**: Jacobson et al. 1992 Table I (n = 9; the text quotes AddP PCSA 1.10
  cm2, the table 1.94, used). Stamenkovic et al. 2014 (two AdP heads, combined PCSA 3.19
  cm2) is recorded as an alternative; the MUSIC path is a single head.
- **Force** = PCSA x 86.3 N/cm2: the least-squares specific tension of MyoHand's OP,
  EPB and APL against Jacobson's PCSA (individually 176.5, 97.9, 60.5 N/cm2, so
  MyoHand implies no single value).
- **Length range**: static `lengthrange` written by `scripts/generate_thenar_muscles.py`, a rigid tendon of
  slack length `(L_MT(q = 0) - L_fo cos(alpha)) / 1.033` (Barry et al. 2018, Eq. 1), so
  the class's normalised fibre-length range 0.75-1.05 spans the same range of L_fo.
  MUSIC's fixed values (`source_lengthrange_m`, which do not cover MUSIC's own tendon
  lengths) are kept in the table for reference only.
- **Known issue**: MUSIC's straight AdP path gives ~47 mm excursion over the thumb range
  against 34 mm fibres, so its normalised length spans ~0.2-1.55 (no active force when
  short, strong passive force when long). Barry et al. 2018 used two heads with wrapping
  surfaces; their model (simtk, MIT) would give a better path.
- Activation dynamics and force-length shape come from the class, as for OP.

## Scaling metadata

Values are absolute SI. Thenar rows tag `force_N` and `pcsa_cm2` with `scales_with:
mass`, `optimal_fiber_length_m` with `length` (reference segment: hand); passive rows are
`scales_with: none`. These tags are provenance metadata only; subject scaling comes in
later PRs.
