# Hand model against the literature

Where the hand stands against published data after each change of the hand rebuild: one table per step,
with the model value next to the published data point, its spread, the reference and the protocol or
posture it was measured in. Pass/fail tests live in `tests/`; this page records the numbers.

The tables below are generated by `scripts/hand_literature_comparison.py` from
`myo_sim/build/data/hand_literature.json` (literature values in `quantities`, model values in `steps`);
`tests/test_hand_literature.py` checks that the page matches the data file and that the latest step's
geometric values match the current model.

```bash
uv run python scripts/validate_hand_function.py --out results.json         # tenodesis, grip, pinch (about 5 min)
uv run python scripts/hand_literature_comparison.py --record <id> --title "..." --summary "..." \
    --hand-function results.json [--before <previous id>]                    # record a step, rewrite this page
uv run python scripts/hand_literature_comparison.py                          # rewrite this page only
```

## How the model values are measured

- **Tenodesis, grip, lateral pinch:** the McFarland et al. 2023 protocols of
  `scripts/validate_hand_function.py` on `myoarm_r` (method: `hand-function-validation.md`). The grip is
  re-optimised for each step (balanced wrist, 0.15 s); "settled" holds the same levels for 2 s.
- **Fingertip soft tissue:** Dallard et al. 2018 measure D_N0 on MRI from the distal palmar corner of the
  phalanx, perpendicular to its long axis, to the skin. In the model: palmar rays (the pad normal made
  perpendicular to the phalanx axis, which runs from the DIP centre to the farthest bone vertex) through
  the bone's mid-line over its last 6 mm, from the outermost collision geom (pad or capsule) to the bone
  mesh; the largest value. Digits 3-5 and the thumb are compared with the index value, the only one
  measured.
- **Palm pads:** the same ray along each pad's normal, from the pad surface to the nearest metacarpal
  bone mesh. Published thicknesses are muscle only, so they are lower bounds.
- **Active fist:** FDS and FDP at full activation for 1 s, wrist neutral and thumb locked at 0, elbow
  90 deg; only the model's own contact pairs collide. Fingertip to palm is the signed distance from the
  distal collision geoms (capsule and pad) to the nearest palm collision geom; penetration counts only
  contacts between two hand geoms.

**Why the trends stay out of reach.** A straight path from a trapezial or retinacular origin to the
metacarpal shaft crosses an abduction axis that lies in the metacarpal base: origin and insertion lie on
opposite sides of the axis, so the path is longest near neutral and its abduction moment arm falls toward
zero as the thumb adducts. Smutz's OP, FPB and APB arms grow toward adduction (and AdP's fall toward
adduction), which needs origin and insertion on the same side of the axis. A scan over the four tilt
sides and axis positions along the metacarpal confirms it: the OP and APB trends turn only with the
abduction axis 6-12 mm proximal of the S2 axis point, at or beyond the proximal end of the metacarpal
(in the trapezium), outside Hollister's location (12.5 ± 6.2 % of the length, -2 to +4 mm from that
point). Hollister's axes improve the
extrinsic CMC arms (APL becomes an extensor, as in Smutz; EPB an abductor) but lower FPL's CMC flexion
arm further (4.2 -> 1.3 mm against 14.3 ± 4.0 mm).

**Outcome.** The thumb-intrinsic Smutz match got worse (RMS z 1.29 -> 1.43) and the pinch moved away
from the in-vivo mean (still inside its band), so the axes were not changed. Wrapping the intrinsic paths
over the metacarpal base or the sesamoids is the remaining lever for the trends, together with the
extrinsic findings below.

## Open checks before release

Adopted values that the literature questions, to be checked once more before the release of the
revised hand. Items that a later step resolved say so.

- **Specific tension of the hand intrinsics: 86.3 N/cm2** for all intrinsics (OP keeps 180 N). This is
  the thenar precedent, a fit to MyoHand's earlier forces, not a measured hand value. At this value the
  index MCP abduction moment with both DI1 heads (1.05 N m) equals the in-vivo first dorsal interosseous
  moment (Infantolino & Challis 2014, about 1.0 N m) but is 39-57 % of the RIHM norms (McGee et al. 2020:
  2.7 / 1.8 N m, men / women, sling at the PIP after Schreuders et al. 2006), i.e. about 2x below. The
  little-finger abduction moment (1.02 N m) lies between the women's and men's norms (0.95 / 1.56 N m).
  Published values span 35 N/cm2 (Brand et al. 1981) to 55 N/cm2 (O'Brien et al. 2010, quadriceps in
  vivo); Holzbaur et al. 2005 use 45 N/cm2 for the forearm muscles.
