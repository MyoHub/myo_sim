# Marker sets

Standard motion-capture marker sets as optional site overlays. Each `*.xml` file holds one `<site>` per marker inside a
`<body>` named like the model body it belongs to, positioned in that body's frame. `myo_sim.markersets.add_markerset(spec, name)`
adds the sites to a loaded, uncompiled spec; no registered model includes them. The site class records how well a
position is known (`myomarker_anatomical`, `myomarker_reference`, `myomarker_fitted`, `myomarker_nominal`), and the
header of each file lists its sources.

The `myomarker_fitted` sites of `bath_running.xml` are generated by `scripts/fit_markersets_bath.py` from the published
static trials of the Bath dataset; the citation, method and fit residuals are in `myo_sim/build/data/markersets_bath.json`.

The Plug-in Gait, CMU and OptiTrack sets contain no copied positions: marker names follow the published documentation,
and each marker sits on an existing model landmark site or was placed from the written description. The CMU Graphics Lab Motion Capture Database was
created with funding from NSF EIA-0196217.
